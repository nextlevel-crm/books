# Books by Dharmendra Satapathy

The books site at nlehni.com, served by GitHub Pages from this repository.

- `index.html` — the shelf, one card per book
- `<book>/` — one folder per book: `index.html` (the page-turning reader), the PDF, page images `p1.jpg…`, thumbnails `t1.jpg…`, `cover.jpg`, `share.jpg`
- `assets/` — the page-flip library shared by every reader
- `CNAME` — the custom domain for GitHub Pages

Push to `main` and the site updates within a minute or two.
